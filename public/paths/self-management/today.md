# Список дел на сегодня

Каждое утро соберите короткий рабочий список из четырёх источников:

- следующих шагов активных проектов;
- срочных задач на текущую дату;
- нескольких подходящих несрочных дел;
- рутин, запланированных на сегодня.

План — это намерение, а не обязательство. Не нужно корить себя за невыполненный пункт. Если список регулярно остаётся незавершённым, уменьшите нагрузку на следующий день.

Список должен отвечать на вопрос «что делать сейчас», не требуя повторного планирования в момент, когда пора действовать.
